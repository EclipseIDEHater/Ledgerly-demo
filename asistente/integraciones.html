Pasos siguientes · Medición

Haz visible lo que ocurre en tu landing.

Una página bonita no es suficiente. Analytics y Pixel te muestran qué personas llegan, qué mensaje las convence y dónde abandonan. Sigue esta guía después de tener tu página publicada.

01

Google Analytics 4

Sirve para entender el recorrido completo: visita, interacción y conversión.

  1. Entra a analytics.google.com y crea una propiedad para tu producto.
  2. En Flujos de datos, crea un flujo web con el dominio de tu landing.
  3. Copia el Measurement ID, que tiene el formato G-XXXXXXXXXX.
  4. Abre el index.html de tu landing y pega el siguiente bloque dentro de <head>, antes de </head>.
index.html · dentro de <head>
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
  1. Reemplaza el ID de ejemplo por el tuyo y publica la página.
  2. En DebugView, verifica que Analytics reciba tu visita.
  3. En el evento de tu CTA, registra una acción con nombre descriptivo:
app.js · evento del botón principal
document.querySelector('#cta').addEventListener('click', () => {
  gtag('event', 'cta_click', {
    variant: new URLSearchParams(location.search).get('variant') || 'a'
  });
});
Qué medir: no te quedes con page views. Define una conversión, por ejemplo waitlist_submit, y úsala para evaluar si la landing funciona.
02

Meta Pixel

Ayuda a medir campañas de Meta y crear audiencias de personas que interactuaron con tu página.

  1. Entra a business.facebook.com/events_manager y crea una fuente de datos de tipo web.
  2. Copia el Pixel ID numérico.
  3. Pega este código dentro de <head> de tu landing y reemplaza PIXEL_ID.
index.html · dentro de <head>
<script>
  !function(f,b,e,v,n,t,s){if(f.fbq)return;n=f.fbq=function(){n.callMethod?
  n.callMethod.apply(n,arguments):n.queue.push(arguments)};if(!f._fbq)f._fbq=n;
  n.push=n;n.loaded=!0;n.version='2.0';n.queue=[];t=b.createElement(e);t.async=!0;
  t.src=v;s=b.getElementsByTagName(e)[0];s.parentNode.insertBefore(t,s)}
  (window, document, 'script', 'https://connect.facebook.net/en_US/fbevents.js');
  fbq('init', 'PIXEL_ID');
  fbq('track', 'PageView');
</script>
  1. Publica y usa la herramienta Test Events de Meta para confirmar el PageView.
  2. Cuando una persona complete tu formulario, registra un Lead:
app.js · después del registro
document.querySelector('#waitlist-form').addEventListener('submit', () => {
  fbq('track', 'Lead');
});
Privacidad: informa qué herramientas usas y solicita consentimiento cuando aplique. No envíes datos sensibles ni correos directamente en eventos.
03

Conjunto mínimo de tracción

Mide el recorrido completo, no una métrica aislada.

Visitas y fuenteCuántas personas llegan y desde dónde. Es el denominador de todas las tasas.
Clic en CTAIntención inicial: clics en CTA ÷ visitas.
Conversión finalResultado elegido: registros, demos o compras ÷ visitas.
Duración y reboteAyudan a ubicar fricción, pero no reemplazan una conversión. Compara siempre por variante y fuente.
Regla: define una acción principal, registra la variante A/B y cambia una sola hipótesis por experimento.
