Pasos siguientes · Experimentos

No adivines qué landing convierte más.

Un experimento A/B muestra dos versiones de una misma página a personas parecidas. Cambias una hipótesis, mides el mismo objetivo y dejas que los datos te ayuden a decidir.

01

Formula una hipótesis

Empieza por una objeción o una pregunta, no por cambiar colores al azar.

Si cambiamos...“Encuentra tu tutor”por...“Aprueba tu próximo parcial con ayuda”entonces esperamos...Más registros en la lista de espera

La variante A es tu control: la versión actual. La variante B prueba una alternativa. Cambia solo el título, el CTA o una imagen, pero no todos a la vez.

02

Publica las dos variantes

Esta aplicación usa una URL simple para simular el reparto de tráfico.

  1. Deja la versión original disponible con ?variant=a.
  2. Publica la versión alternativa con ?variant=b.
  3. Configura tu herramienta de anuncios, enlaces o redirección para enviar tráfico a ambas URLs.
  4. Mantén iguales el público, el periodo, el formulario y el objetivo.
Controltusitio.com/?variant=a
Experimentotusitio.com/?variant=b
03

Mide una conversión real

El ganador no es quien recibe más visitas, sino quien logra mejor el resultado del negocio.

Métrica primariaConversión del CTA o envío del formulario. Elige una sola.
Métricas secundariasScroll, clics, tiempo en página o abandono. Sirven para entender, no para declarar un ganador.
Calidad¿Los registros pertenecen a la audiencia y muestran interés real?
Evento recomendado
gtag('event', 'waitlist_submit', {
  variant: new URLSearchParams(location.search).get('variant') || 'a'
});
fbq('track', 'Lead');
04

Evalúa sin engañarte

Antes de tomar una decisión, revisa estas condiciones.

  1. Espera hasta tener suficientes visitas y conversiones para que el resultado no dependa de unas pocas personas.
  2. Compara el mismo periodo y el mismo origen de tráfico.
  3. No detengas el experimento apenas una variante vaya ganando durante unas horas.
  4. Si gana B, documenta qué cambió y convierte ese aprendizaje en la siguiente hipótesis.
Regla práctica: una prueba A/B no responde “¿cuál diseño es más bonito?”. Responde “¿qué mensaje ayuda a más personas a dar el siguiente paso?”.
